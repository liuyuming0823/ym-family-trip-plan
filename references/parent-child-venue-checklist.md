# 亲子景点适配性检查清单

> 出行前对每个备选景点逐项检查，筛除不适配的景点。此清单不替代现场判断，但能大幅降低「到了才发现不行」的风险。

---

## 一、通用检查项（所有年龄段适用）

| 检查项 | 检查方法 | 达标标准 |
|--------|----------|----------|
| 母婴室 | 官网设施说明 / 电话咨询 / 大众点评搜「母婴室」 | 0-3岁必选，3-6岁加分项 |
| 无障碍通道 | 官网 / 地图查「无障碍」 / 评论搜「推车」 | 有电梯或坡道，推车可通行 |
| 遮阳/避雨 | 卫星图看绿化率 / 评论搜「暴晒」「阴凉」 | 有室内区域或树荫遮蔽 |
| 休息区 | 官网 / 评论搜「休息」「座椅」 | 每30分钟路程内有座椅或休息区 |
| 厕所密度 | 地图查厕所标注 / 评论搜「厕所」 | 每1小时活动范围内有厕所 |
| 安全围栏 | 官网安全说明 / 评论搜「围栏」「护栏」 | 水域/高处有符合标准的围栏 |
| 餐饮配套 | 地图查周边餐厅 / 官网餐饮说明 | 步行5分钟内有亲子友好餐厅 |
| 停车/交通 | 官网停车说明 / 地图查停车场 | 有停车场或公共交通可达 |

## 二、分龄重点检查项

### 0-3岁重点项

| 检查项 | 达标标准 | 检查方法 |
|--------|----------|----------|
| 哺乳空间 | 有独立母婴室（非厕所内） | 电话确认 / 评论搜「哺乳」 |
| 换尿布台 | 母婴室内有换尿布台 | 电话确认 |
| 推车通行 | 全程推车可通行无台阶 | 评论搜「推车」「台阶」 |
| 噪音水平 | 非高噪音环境（<80分贝） | 避免室内游乐场高峰时段 |
| 室内/遮蔽 | 有室内区域可避晒避雨 | 卫星图+官网 |
| 拥挤度 | 非极致拥挤场所 | 避开节假日高峰 / 选工作日 |

### 3-6岁重点项

| 检查项 | 达标标准 | 检查方法 |
|--------|----------|----------|
| 互动设施 | 有可触摸/可参与的区域 | 官网活动介绍 / 评论搜「互动」 |
| 安全围栏 | 水域/高处有围栏 | 评论搜「安全」「围栏」「危险」 |
| 儿童厕所 | 有儿童专用厕所或矮便池 | 评论搜「儿童厕所」 |
| 活动区域 | 有跑跳空间（非全程静坐） | 官网 / 评论搜「场地」「空间」 |
| 排队情况 | 主要项目排队<30分钟 | 评论搜「排队」/ 选非高峰时段 |

### 6-12岁重点项

| 检查项 | 达标标准 | 检查方法 |
|--------|----------|----------|
| 知识含量 | 有教育价值（科普/历史/文化） | 官网介绍 |
| 互动体验 | 有动手操作区或体验活动 | 官网 / 评论搜「体验」「动手」 |
| 导览/讲解 | 有儿童导览或讲解服务 | 官网 / 电话确认 |
| 难度适配 | 内容难度适配6-12岁认知 | 评论搜「适合几岁」/ 官网推荐年龄 |
| 探索空间 | 有自主探索区域 | 官网 / 评论 |

### 12岁+重点项

| 检查项 | 达标标准 | 检查方法 |
|--------|----------|----------|
| 兴趣匹配 | 内容与孩子当前兴趣相关 | 出行前与孩子讨论 |
| 自主空间 | 有可独立探索的安全区域 | 官网 / 地图查区域范围 |
| 文化深度 | 有足够文化/历史/科技深度 | 官网介绍 / 评论 |
| 社交属性 | 可与同伴或家长讨论分享 | 内容有话题性 |

## 三、检查方法

### 方法1：官网核实
- 查看景点官网的「设施服务」「无障碍」「亲子」等页面
- 确认母婴室、无障碍通道、停车、餐饮等硬性指标

### 方法2：评论搜索
- 大众点评/美团：搜索关键词「带娃」「推车」「母婴室」「儿童」「排队」「安全」
- 小红书：搜索「目的地+亲子/带娃/几岁」，看真实体验帖
- 知乎/马蜂窝：搜索目的地的亲子游记，关注踩坑描述

### 方法3：地图查配套
- 高德/百度地图：查景点周边500米内的餐厅、厕所、停车场、地铁站
- 卫星图：看绿化率和室内外比例，判断遮阳/避雨条件

### 方法4：电话确认
- 对关键指标（母婴室/换尿布台/儿童椅/推车通行）电话直接确认
- 询问高峰时段和推荐游览时间

### 方法5：社交媒体验证
- 抖音/快手：搜索景点名称，看实拍视频判断环境
- 微信公众号：搜索景点相关亲子游攻略文章

## 四、不适配信号

出现以下任一信号，建议更换景点：

- 评论中多次出现「不适合带小孩」「带孩子去很受罪」
- 无母婴室且周边500米无替代方案（0-3岁直接淘汰）
- 全程无遮蔽、需暴晒1小时以上（低龄段淘汰）
- 排队普遍超1小时且无快速通道
- 多条评论提及安全隐患（围栏缺失/水域无隔离）
- 官网明确标注「不建议X岁以下儿童」
