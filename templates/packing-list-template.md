# 必带物品清单模板

> 按孩子年龄选择对应分档，按场景分类核对。三级优先：必带（缺了影响行程）/ 建议带（提升体验）/ 可选（锦上添花）。每项标注数量。

## 分档选择
- 当前孩子年龄档：☐ 0-3岁 ☐ 3-6岁 ☐ 6-12岁 ☐ 12岁+
- 出行天数：___天
- 目的地类型：☐ 城市 ☐ 自然 ☐ 主题乐园

## 出发前自查清单

- [ ] 按孩子年龄档核对物品，无遗漏
- [ ] 必带项全部打包（逐项打勾）
- [ ] 药品检查有效期
- [ ] 防晒霜/防蚊液为儿童装（低龄段）
- [ ] 备用衣物按天数+1套
- [ ] 电子设备充满电+带充电宝
- [ ] 雨天增补物品已加入（雨衣/防水鞋套/备用干燥衣物/防水袋）
- [ ] 食物过敏史相关药品随身携带
