## 二、分龄安全重点

### 0-3岁重点
| 重点 | 措施 | ☐ |
|------|------|---|
| 防误吞小物 | 检查酒店房间/景点环境有无散落小物（硬币/纽扣/电池） | ☐ |
| 防跌落 | 酒店床铺加防跌垫/婴儿床栏杆检查 | ☐ |
| 防窒息 | 食物切成小块，避免整颗葡萄/坚果/硬糖 | ☐ |
| 防烫伤 | 远离热水壶/热水器/餐厅热汤 | ☐ |
| 婴儿安全座椅 | 自驾必须使用反向式婴儿座椅 | ☐ |

### 3-6岁重点
| 重点 | 措施 | ☐ |
|------|------|---|
| 防走失 | 人流密集场所全程牵手或防走失手环，约定走失集合点 | ☐ |
| 防溺水 | 水域（海边/泳池/湖边）必须伸手可及，不离开视线 | ☐ |
| 防高处跌落 | 检查围栏高度和间隙，不让孩子攀爬护栏 | ☐ |
| 防陌生人接触 | 教孩子「不跟陌生人走、不接陌生人给的东西」 | ☐ |
| 防交通 | 过马路牵手，不在车道奔跑 | ☐ |

### 6-12岁重点
| 重点 | 措施 | ☐ |
|------|------|---|
| 交通安全 | 教导交通规则，骑自行车/滑板戴头盔 | ☐ |
| 运动防护 | 户外运动带护膝/护肘/头盔 | ☐ |
| 防走失 | 约定集合地点和紧急联络方式，让孩子背诵家长电话 | ☐ |
| 防中暑 | 高温户外活动每30分钟补水+阴凉休息 | ☐ |
| 水上安全 | 乘船穿救生衣，不单独下水 | ☐ |

### 12岁+重点
| 重点 | 措施 | ☐ |
|------|------|---|
| 电子设备使用约定 | 约定使用时间和场合，旅行中保持联络通畅 | ☐ |
| 紧急联络方式 | 让孩子记住家长电话+酒店地址+报警电话 | ☐ |
| 独立探索安全 | 约定活动范围+返回时间+保持联络 | ☐ |
| 网络安全 | 提醒不透露个人信息/位置给陌生人 | ☐ |
| 活动风险评估 | 户外运动（攀岩/骑行/水上）确认装备和安全指导 | ☐ |

### 紧急情况处理步骤
1. **保持冷静**：家长情绪稳定是孩子安全感的来源
2. **评估情况**：判断伤情/病情严重程度
3. **轻伤处理**：用急救包自行处理（创可贴/消毒/退烧）
4. **重伤/急病**：立即拨打120或前往最近医院，同时通知第二联络人
5. **走失处理**：
   - 立即在走失点附近寻找（半径50米）
   - 3分钟内未找到→通知景点/商场安保人员
   - 5分钟内未找到→拨打110报警
   - 提供孩子当日全身照+衣着特征+姓名
6. **保险报案**：就医后保留所有票据和诊断证明，24小时内联系保险公司报案
